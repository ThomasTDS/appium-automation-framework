# Pasta de aplicativos

Coloque aqui o APK do aplicativo sob teste (ex.: `android-demo-app.apk`).

Arquivos `.apk`/`.ipa` não são versionados neste repositório (ver
`.gitignore`), pois são binários grandes e de distribuição própria do
fabricante do aplicativo. As instruções de download estarão no README
principal do projeto assim que a suíte de testes for publicada.
